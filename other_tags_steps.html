THE LITTLE THINGS: HOW TO MAKE IT

This guide explains only the paragraph, line break, divider, preformatted text, and internal CSS used in the Other Tags practical.

Steps to Make the Page

  1. Create the HTML document structure and set the page title.
  2. Write normal story text inside a <p> paragraph.
  3. Use <br> when the next sentence should start on a new line.
  4. Use <hr> to place a thematic divider between story sections.
  5. Use <pre> when spaces and line breaks in code must be preserved.
  6. Place the example code inside <pre> and escape angle brackets with &lt; and &gt;.
  7. Add internal CSS inside the <style> tag to style the page.
  8. Open the page in a browser and check the paragraph, breaks, divider, and code block.

Internal CSS Tutorial

Internal CSS is written inside a <style> tag in the page's <head>. It controls the appearance of the tags without changing the HTML content.

<style>
  p {
    line-height: 1.7;
    color: #c89db8;
  }

  hr {
    border: 0;
    border-top: 1px solid #73365f;
  }

  pre {
    padding: 1rem;
    overflow-x: auto;
    background: #07020d;
  }
</style>

p, hr, and pre are selectors. The declarations set spacing, colors, borders, padding, and overflow behavior.
