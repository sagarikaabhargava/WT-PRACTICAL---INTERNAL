FORMATTING A FEELING: HOW TO MAKE IT

This guide explains only the HTML used in the Formatting a Feeling practical page.

Steps to Make the Page

  1. Start with the HTML document structure and set the page title.
  2. Use headings from <h1> to <h6> to create the story hierarchy.
  3. Write the story inside <p> paragraphs.
  4. Use <b>, <i>, <u>, and <s> for text styles.
  5. Use <mark> to highlight the most important sentence.
  6. Use <sub> and <sup> for subscript and superscript examples.
  7. Open the file in a browser and check the heading order and text formatting.

Formatting Page Code

<h1>THE DAY I STOPPED RUSHING</h1>
<h2>A tiny story about taking the long way home</h2>
<h3>18 September, after class</h3>
<h4>The detail I almost missed</h4>
<h5>A small choice can change the mood</h5>
<h6>End note: take the long way sometimes</h6>

<p>I was about to sprint for the bus. <b>That felt brave.</b>
<i>The evening felt softer.</i> <u>The walk was worth it.</u>
<s>I needed to rush home.</s>
<mark>This part felt like mine.</mark></p>

<p>Water is H<sub>2</sub>O and a power is 100<sup>3</sup>.</p>

Internal CSS Tutorial

Internal CSS is written inside a <style> tag in the page's <head>. A selector chooses an HTML element, and declarations change its appearance.

<style>
  h1 {
    color: #fff5fb;
    font-family: Georgia, serif;
  }

  mark {
    background-color: #ff6fae;
    color: #100718;
  }
</style>

h1 and mark are selectors. color, font-family, and background-color are properties. The values after the colon control the final style.
