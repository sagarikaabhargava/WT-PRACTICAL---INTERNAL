FONTS & PHOTO DUMPS: HOW TO MAKE IT

This guide explains only the HTML, font, and image code used in the Fonts & Photo Dumps practical page.

Steps to Make the Page

  1. Start with the HTML document structure and set the page title.
  2. Add a font provider link inside <head> to load different font styles.
  3. Create a main content panel using a <div>.
  4. Use separate elements for the display-font sample and code-font sample.
  5. Write a short photo-dump description using a <p> tag.
  6. Add images with <img>, a source URL, and useful alternative text.
  7. Use CSS grid to place the images into a responsive gallery.
  8. Open the page in a browser and check that both images and fonts load correctly.

Fonts and Image Code

<link href="https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;700
&family=Playfair+Display:wght@600;700&display=swap" rel="stylesheet">

<div class="font-sample-2">photo dump // coffee foam // sunset walk</div>

<p>A tiny moodboard from an ordinary day.</p>

<div class="gallery">
  <img src="coffee.jpg" alt="Coffee on a cafe table">
  <img src="sunset.jpg" alt="A warm evening view">
</div>

Internal CSS Tutorial

Internal CSS is written inside a <style> tag in the page's <head>. It is useful when one HTML page has its own colors, fonts, spacing, and gallery design.

<style>
  .gallery {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 1.5rem;
  }

  .gallery img {
    width: 100%;
    object-fit: cover;
  }
</style>

.gallery and .gallery img are class selectors. display, grid-template-columns, gap, width, and object-fit are CSS properties.
