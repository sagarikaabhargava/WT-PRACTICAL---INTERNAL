MOVING THOUGHTS BAR: HOW TO MAKE IT

This guide explains only the marquee text, image, hyperlink, animation, and internal CSS used in the Moving Thoughts Bar practical.

Steps to Make the Moving Bar

  1. Create the HTML document structure and set the page title.
  2. Create a container with overflow: hidden so content stays inside the bar.
  3. Place the moving text inside a child element.
  4. Add the image with <img> and a descriptive alt value.
  5. Add a hyperlink with <a> so the moving content can open another page.
  6. Use an internal CSS @keyframes animation to move the content from right to left.
  7. Repeat the text when needed so the animation appears continuous.
  8. Open the page in a browser and test the moving text, image, and hyperlink.

Moving Bar Code

<div class="ticker-box">
  <div class="ticker-text">
    thoughts for today •
    <a href="formatting.html">Read the story</a>
    <img src="coffee.jpg" alt="Coffee on a table">
  </div>
</div>

Internal CSS Tutorial

Internal CSS is written inside a <style> tag in the page's <head>. The selector chooses an element, the property names the style, and the value controls the result.

<style>
  .ticker-box {
    overflow: hidden;
    white-space: nowrap;
  }

  .ticker-text {
    display: inline-block;
    animation: move-thoughts 15s linear infinite;
  }

  @keyframes move-thoughts {
    from { transform: translateX(0); }
    to { transform: translateX(-50%); }
  }
</style>

overflow hides content outside the bar, white-space keeps the line unbroken, and @keyframes defines the movement.
