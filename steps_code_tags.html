HOW THIS LITTLE SITE WAS BUILT

This extra practical explains the process behind the four Core Practical pages and the two project pages.

Steps Used

  1. Create a separate HTML file for each topic.
  2. Add the document structure: html, head, and body.
  3. Add page information such as the character set, viewport, and title.
  4. Write the topic content using semantic HTML tags.
  5. Add hyperlinks so every page can return to the home page and reach an internal section.
  6. Add CSS for layout, fonts, colors, spacing, responsive design, and animation.
  7. Open the files in a browser and test every link, image, and interactive element.

Basic Page Code

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My Web Page</title>
  </head>
  <body>
    <h1>My Story</h1>
    <p>A short description goes here.</p>
  </body>
</html>

Testing Checklist

Check that the page opens in a browser, every home link works, internal links jump to the correct section, images have alt text, and the layout works on both desktop and mobile screens.
